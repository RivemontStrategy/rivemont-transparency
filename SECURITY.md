# Security

If you find a vulnerability in Rivemont, in this code or on rivemont.xyz, please email **contact@rivemont.xyz** with:

- what is affected (a file and line here, or a page / endpoint on the site),
- how to reproduce it, and what an attacker could do with it,
- whether it is already public.

Please do not test against other people's accounts or funds, do not run load or denial-of-service tests against the
site, and give us reasonable time to fix an issue before you disclose it.

We will acknowledge your report, keep you informed while we fix it, and credit you if you wish. There is no bug bounty
program at this time, and no reward is promised.
